# Dog Explorer 🐶

## Description

Dog Explorer is a web application that uses The Dog API to help users explore dog breeds and view random dog images.

## Features

* View dog breed information
* View random dog images
* Search for dog breeds (bonus feature)
* Responsive design for desktop, tablet, and mobile devices

## API Used

The Dog API

## How to Run

1. Download or clone the project.
2. Create a file named `config.js` inside the `js` folder.
3. Copy the contents from `config.example.js` into `config.js`.
4. In `config.js`, replace:

    const API_KEY = "YOUR_API_KEY_HERE";

    with your actual Dog API key.

5. Open `openapi.html` in a web browser.

## Navigation

* **Breeds**: Displays dog breed information from the Breeds endpoint.
* **Random Dogs**: Displays random dog images from the Images endpoint.
* **Search Dogs**: Searches for specific dog breeds (bonus feature).
